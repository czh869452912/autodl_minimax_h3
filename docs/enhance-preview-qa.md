# Enhance 对比与全屏预览

2026-10-25 · beta.6

- 结果页的对比入口移至图片右下角绝对定位浮层，不参与预览和历史区域的高度分配。
- 按下显示原图，松开恢复结果；原图层预先挂载。切换版本、打开全屏或应用退入后台时清理按住状态。屏幕阅读器可通过激活动作切换。
- 对比按钮与打开全屏的图片点击区域为兄弟节点，避免对比触发全屏。
- 全屏使用深色背景、安全区域、顶部关闭及底部缩放/版本导航。双指缩放、双击缩放、下滑关闭继续可用。
- 入场等待原生 Modal 的 onShow，使用原生驱动淡入和轻缩放；退出动画结束后才调用父级关闭。系统减少动态效果时不播放过渡。

验证：结果页、全屏、工作区共 23 项测试通过，TypeScript 检查通过。最终入场时序调整后，全屏 3 项测试再次通过，覆盖 onShow 之前不启动动画及退出完成前不卸载。

Android 模拟器检查了 1080×2400 与 720×1280 布局、全屏缩放、关闭与返回。没有额外提交付费 Enhance；原图/结果切换及浮层不改变布局使用固定版本数据回归测试验证。最后的 onShow 时序调整通过自动化测试，未再次进行模拟器安装。
