# 综合创作 App 实施记录

基线：[交互与数据设计 v1.3](creative-app-interaction-data-design.md)。2026-10-23 开始实施。数据库当前为 v27，交付版本为 1.5.0-preview.2。已实现首条创作链及下列增量；整体路线尚未全部完成，旧媒体迁移仍为 CATCHUP，真实服务及手机交互验收未通过前不视为正式发布。

## 增量 01：任务与输出引用兼容

已实现：

- jobs/repository.ts 的 workflow_jobs 写入由 INSERT OR REPLACE 改为 ON CONFLICT DO UPDATE，保留身份与原 created_at；内存仓库采用相同创建时间语义。
- jobs/artifactStatements.ts 统一结果快照写入：原位 upsert 保留输出，只删除快照中不再存在的输出。常规仓库及持久化执行器共用，仍处于各自事务内。
- 对结果所属 job 不一致及重复 artifact ID，在执行 SQL 前拒绝。
- 新增真实 SQLite 外键验收：父任务与保留输出更新不删除引用；有引用的输出移除失败后，先前写入、job 状态、事件及任务清理均回滚。

验证：

- npm run typecheck：通过。
- npm test -- --runInBand src/jobs src/workflows/executor src/tasks/repository.test.ts：17 套、206 项通过；默认跳过的跨进程测试另由下列脚本执行。
- npm run verify:process-recovery：5 个场景、10 个独立进程通过（pending、unknown、handle、redaction、part）。这是既有执行器进程恢复验证，不是新设计的旧备份隔离验收。
- git diff --check：通过（Git 提示 Windows 换行转换，不影响检查结果）。

限制：本增量没有新增创作表、切换写入权威、实现账号/授权账本、增加项目页或 NovelAI API。测试子表用于验证 FK 行为，不等同于实际创作迁移已验收。任务删除遇引用时目前按原事务报错回滚；新领域接入时仍需提供“改为归档”的明确交互。

## 增量 03：备份中的执行隔离

- v15 添加恢复代次与隔离记录，恢复流程改为复制到独立 staging DB、迁移、隔离、校验之后才替换当前库。
- 从备份带入的 job/operation（包括 READY/PENDING 和无 job 的导出）全部隔离；其未完成操作置 BLOCKED。数据库触发器阻止旧任务重入队或重新 claim。
- 新恢复代次不恢复旧执行资格。当前 UI 可查看旧任务，恢复文件/对账的精细放行仍待后续完成。
- 验证：264 项存储、执行器、根布局测试及类型检查通过。故障注入验证 staging 失败不替换当前库、隔离事务失败不留下半更新；旧 pending 快照与重新排队均无法 dispatch。
- 范围限制：目前实现的是既有任务执行隔离；尚未实现的授权账本和 Agent 自动计划仍须接入相同恢复代次边界。完整创作文件备份包尚待实现。

## 增量 08：不可覆盖凭据代次与授权账本

- v19 增加账号绑定、凭据代次、默认映射、授权、额度预留及只追加事件。新 SecureStore key 按代次分配；身份字段不可改写，读取时校验摘要，缺失/替换不回退默认 Token。
- 设置页新增 NovelAI 持久令牌验证、连接、更换与断开。使用只读 subscription 接口验证；公开 Swagger 的 AccountInformationResponse 无稳定 principal ID，当前明确使用 credential_bound，不从邮箱/余额推断身份。参考 https://api.novelai.net/docs/ （2026-10-23）。
- 预留检查项目/操作/单位/请求哈希、估价有效期、请求数和金额。未知费用独立限额且不能与硬金额上限并用；UNKNOWN_HELD 不自动释放。发送前事务再次校验授权 revision、账号代次、恢复 epoch 和估价。
- Token 轮换撤销旧授权、停用旧代次；已发送请求仍可用原代次只读查询。恢复备份清空默认映射、撤销授权并保留历史占用，不能以旧账本续用额度。
- 验证：22 套、135 项及类型检查通过；包含独立 SQLite 连接争抢最后名额、原子事件失败、零费用请求计数、超额结算、重复回调、跨项目、恢复旧备份、验证与切换竞争、密钥槽位篡改和 principal 不符。
- 范围：账本契约及 NovelAI 连接 UI；尚未接入生成 dispatch。AutoDL 新账号验证、生成页面授权与 Agent 工具接入仍在后续；现有 H3 设置/提交链未宣称已纳入该新账本。未进行真实账号 API 验收。

## 增量 11：H3 授权提交、精确账号执行与候选归档

- 草稿生成确认显示凭据代次、单次请求和未知费用；15 分钟授权。任务、额度预留、冻结输入、草稿状态、独立回执与队列在同一事务提交。
- H3 创作任务发送/查询使用不可覆盖凭据代次。发送前再次核验请求哈希、租约、恢复隔离和授权；换账号不重定向旧请求。网络结果不明保留消费占用，不能自动重复发送。
- AutoDL ComfyUI 未提供已确认的只读身份接口，明确仅作本地凭据绑定（verified_at=0）；首次请求由服务商校验。不从余额或邮箱推断账号身份。
- 下载提交事务将视频入库为候选版本并持久 pin，重放不重复，改变同输出内容会拒绝；不修改资产默认、项目固定版本或镜头选定版本。资产详情可播放视频。创作任务删除引导使用归档，保留消费和来源记录。
- 验证：类型检查、105 项相关测试通过；全量 186 套、1316 项通过，1 套/2 项既有跳过。新增故障覆盖原子回滚、重复提交、账号切换、发送后网络丢失、租约失效、备份隔离和候选归档失败。
- 限制：未进行真实付费 H3 请求或新页面设备验收；实际费用没有可核验回执时仍保留占用。历史作品迁移、NovelAI 生成和 Agent 创作工具继续后续增量。

## 增量 13：NovelAI 基础协议与可恢复原生传输

- 参考官方图片 OpenAPI `https://image.novelai.net/docs/doc.json`（2026-10-23）。基础请求显式保存模型、实际 Seed、尺寸、采样、负面及成对角色提示词；只发送白名单字段，不默认复制未知元数据或加入质量标签。
- 官方接口支持 Accept: application/json，返回 images[].image/index/seed。本实现采用单张 JSON 响应，不解压外部 ZIP；20MB 响应上限与图片尺寸/内容头校验。
- Android 传输在连接前同步写入发送标记，禁止客户端自动连接重试和重定向。响应文件及 SHA-256 持久化后可离线复用；丢失、损坏或请求指纹不同不会重新发送。Token 不写入文件或错误消息。
- 验证：类型检查、3 项协议测试通过；原生 JVM 全套构建/测试成功，新增覆盖持久回执重放、请求后断线、错误指纹、损坏响应和文件中不含 Token。
- 范围：协议与原生传输；图片草稿、队列入库和页面在下一增量衔接。模型 API 真机调用未验证，Vibe/精确参考/图生图/重绘仍未开放。

## 增量 14：NovelAI 图片创作闭环

- 图片草稿页支持正/负面、最多 6 角色及位置、模型/尺寸/Seed/采样参数，底部固定生成入口、自动保存及离页保护。项目、资产和创作入口可进入；生成前单次未知费用授权。
- 使用既有任务/operation/授权账本提交；实际响应 Seed 写入版本配方，输出候选不覆盖默认。按版本继续生成保留同资产来源，也可选图创建 H3 草稿。
- 原生完整响应已保存但任务句柄写入失败时，启动仅核验并重建本地导入任务；响应缺失保持 UNKNOWN，旧备份 epoch 隔离不自动恢复请求。图片进入 CAS 后再事务写入版本，重放不重复。
- 验证：类型检查、13 套 58 项相关测试通过，新增共享执行器测试覆盖发送/查询/归档、实际 Seed、回执失败后离线恢复、缺失响应与旧备份零重发。
- 限制：真实 API 及窄屏设备验收仍待完成；高级参考能力保持关闭，费用未知不按零结算。官方 JSON 契约已核对，模型参数组合尚未逐个账号实测。

## 增量 15：Agent 同源创作工具与范围授权
