# 提示词协作实现与验证

2026-10-25

## 交互

- 图片助手嵌入工作台：窄屏画布下方，宽屏侧边；复用工作台展开/收起动画与减少动态效果设置。
- 协作期间收起图片生成栏，输入框与发送按钮同行，保留画布上下文。
- 多轮流式讨论；支持停止。关闭面板终止当前请求，完成的讨论按草稿在本地保存，重启后恢复。
- 建议包括主描述、负面词及现有角色描述。可编辑后逐项采用或全部采用；支持撤销上次采用。
- 草稿在生成建议后变化时阻止直接覆盖，要求重新讨论。撤销也校验当前草稿，避免覆盖后续修改。
- 视频复用协作组件，仅允许修改镜头提示词。

## 执行边界

复用现有助手模型配置与适配器。每次请求包含当前草稿的显式白名单字段和最近讨论；最多四轮工具循环，每轮最多六个工具调用，有上下文与回答长度限制。

工具仅包括官方 NovelAI 标签搜索、建议约束校验、返回结构化修改建议。不会自动提交媒体生成。保留角色坐标和启用状态，拒绝不存在的角色索引与 Medium 模式不支持的负面词改动。

参考图仅传递存在状态，不发送图片像素，不声称完成视觉分析。视频上下文目前为提示词及工作流标识，并非完整视频参数或素材分析。
