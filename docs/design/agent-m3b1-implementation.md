## 行为与范围

原“确认并生成”系统 Alert 改为现有 `ParameterSheet` 全屏滚动表面。按本次对象、服务与账号绑定版本、实际准备的提示词、负面/角色描述、固定素材版本、规格、消费范围和许可组织。默认不勾选外发与消费；两项均确认后才能调用原 confirm。勾选仅在本地临时保存，取消、系统返回、会话/运行变化会丢弃。重新进入必须重新 prepare 和确认。

图片展示实际请求中的扩展提示词、预设负面描述和角色文本，避免把原输入误当全部外发内容；不序列化整个请求体，避免把媒体编码和凭据作为 UI 内容。账号仅展示绑定与凭据版本标识，不显示令牌，也不把凭据绑定称作已验证账号身份。每次请求次数与图片张数明确区分。未知费用、无金额上限、确认起 15 分钟和结果不明不自动重发沿用原合同。

缺账号时在原位复用 `CreativeAccountPanel`；保存后仍需主动重新核对原草稿。其他准备失败可打开原固定草稿修正，或返回本轮创作。编辑不会提交，原运行/草稿身份保留；从编辑器返回后需重新打开请求。配置错误分类当前按既有错误文案/错误码匹配，后续宜改为领域结构化错误，不宣称全部配置错误已精准分流。

confirm 前重新检查数据库、会话/运行、项目范围及草稿是否归入计划；后台异步 prepare 的旧结果不得打开新会话的审阅。重复确认有本地锁；固定版本、账号及请求绑定继续由原 confirm/submission 服务校验。提交出错丢弃旧审阅，回卡片核查原任务，不把旧授权视为新一轮确认。既有 confirm 中外发许可、消费许可和提交是连续操作，不新增跨操作原子事务；失败后已有记录的清理语义沿用领域服务。

M3b1 完成时计划/批次仍使用原 Alert，项目撤销仍在项目选择器；前者已由 M3b2 迁入共享审阅，后者现归项目概览“项目权限”。视频工作流快照后由 M3b2 补齐；图片处理参数、蒙版来源与超分尺寸由 [改造后复核](agent-post-implementation-review.md) 补齐，未增加蒙版像素预览；本次设备主验为普通图片请求，不能推广为全部媒体路径验收。
