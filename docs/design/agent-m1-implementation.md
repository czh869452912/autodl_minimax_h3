# M1：会话技能选用与范围

日期：2026-11-04。承接 [实施计划](agent-improvement-plan.md) 的 M1a/M1b 和 [50 项操作评估](agent-action-review.md) 的 02、04、05、11–16。当前改动以 `db7aa4d6` 为源码基线，沿用原生 React Native、现有主题及抽屉组件。

## 已实现的任务链

项目标题 → 输入区旁的“技能” → 搜索/查看用途 → 确认用于下次消息 → 回到原输入 → 发送。快速层独立于完整技能目录；管理仍可从会话菜单进入，旧深链接继续兼容。

| 范围 | 入口与操作 | 持久化及影响 |
| --- | --- | --- |
| 下次消息 | 输入旁快速层；“用于下次消息” | 复用 `agent_skill_next_runs`；消息受理事务消费一次，不改项目/全局组合 |
| 项目默认 | 快速层“管理技能与项目默认” | 修改项目组合，仅影响新运行；已有运行保持快照 |
| 全局 | 项目管理页“打开全局技能管理” | 影响继承全局的后续运行；停用版本先确认，复用既有撤销和停止机制 |
| 内置 | 快速层可展开用途；管理目录仍可发现 | 只读；可发现不代表本次已经读取；选技能不授予工具或生成权限 |

镜头上下文移到输入附近，可移除；运行时禁止更改项目、镜头范围及下次技能，并说明原因。项目标题仍留在会话顶部。

## 状态与返回合同

| 状态 | 主操作 | 关闭/返回与数据结果 |
| --- | --- | --- |
| 项目继承 | 保持默认或选择本地技能 | `null` 表示继承；确认删除已有单次覆盖 |
| 编辑未确认 | 选择/取消选择，最多 8 个本地技能 | 关闭、系统返回、拖下均丢弃本次编辑；保留先前已确认选择 |
| 空选 | 明确选择“仅内置技能” | `[]` 是一次有效覆盖，与继承不同 |
| 已固定单次 | 输入旁显示名称或仅内置 | 受理成功后恢复默认；重试仍复用原运行快照 |
| 版本/范围失效 | 重新选择并确认 | 展示失效提示；发送仍服从既有有效性核验 |
| 管理往返 | 推入项目管理页，再正常返回 | 未确认选择留在快速层内存；不把输入/技能正文放进路由；返回重读目录 |
| 运行中 | 等待完成 | 入口与确认禁用；不替换运行快照 |
| 数据库/范围发生变化 | 关闭后重开或重读 | 确认事务校验打开时的 projectId、scope revision、execution epoch；拒绝向新范围写入 |
| 读取/保存失败 | 重读或重新确认 | 错误留在当前任务；失败不冒充成功、不提前清除输入 |

输入组件在打开快速层时保持挂载；关闭后请求恢复输入焦点。文字、光标和已添加附件由现有 composer 状态维护，不新建副本。管理往返的短期编辑不承诺跨进程保存；已确认单次选择与既有输入草稿按原存储恢复。

## 验证与边界

相关 8 个测试套件、121 项测试通过；覆盖真实 SQLite 的单次写入/受理消费、第二次继承、取消、空选/继承差别、管理往返、范围变化拒绝、撤销失效，以及输入文字/光标/附件保留、全局停用确认与重复点击保护。另覆盖 Android 模态根的键盘避让、键盘隐藏后恢复；TypeScript 检查通过。

设备上完成文字＋图片附件→取消、管理往返、确认、重开、发送→第二条继承默认；直接读取本项目单次/运行快照记录验证消费。搜索时发现确认按钮被键盘遮挡，现为快速层启用基于模态根布局的避让，修复后实际点击键盘上方的确认并发送成功；其他抽屉保留原行为。另在约 384dp 宽、2 倍字体下修复标题截断，并验证展开滚动可达管理入口；未验证大字体与键盘叠加。源码和设备证据分开记录，详见 [本轮证据报告](evidence/2026-11-04-m1-skills/README.md)。

测试渲染器不能证明 TalkBack 焦点或完整供应商请求已通过。设备采用本地模型回放，不调用生成供应商。M0 的建议、授权、运行失败、结果未知、候选等广泛状态仍由后续 M3/M4 补齐；本切片不据此宣称 M0 全部完成。

尚未实施：M2 添加技能分阶段、M3 提议/授权/候选重组、M4 计划列表/详情、M5 提炼与历史收口；原项目选择器中的授权撤销暂保留，待 M3 迁移。全局/项目管理目录的安装与历史密度仍需 M2/M5 处理。
