# D005：单次生成使用独立审阅表面

日期：2026-11-05。状态：M3b1 已接入；计划/批次、完整工作流字段与配置恢复待续。承接 D004/F3 的草稿下一步。

原单次请求 Alert 将服务、输入绑定、费用和提交后果放在一段文字中，且不展示实际提示词。改用现有全屏 `ParameterSheet`，保持主题与路由；以任务对象、实际发送内容、账号绑定、固定版本、规格、费用和双许可组织。选择了分区滚动审阅而非继续加长 Alert，代价是增加滚动距离；取消和许可控件可在同一任务内到达。

外发与消费分别勾选，最终确认时复用原领域服务分别记录；勾选本身不授予许可，不替换撤销管理。缺账号可原位修复，修复只改变配置，必须重新准备和审阅原草稿。

当前没有新增路由或全局请求状态。以固定草稿、prepare 的快照和原事务校验维持一致性；范围/数据库变化拒绝旧确认，生成后仍需候选审阅采用。目录登记 `generation-request-review` 与 `generation-request-recovery`，不把非路由表面冒充页面。

本切片只对会话单次请求进行有限设备验证，离线 prepare 替代不得冒充真实账号/供应商端到端。完整范围、回归及后续取舍见 [M3b1](../agent-m3b1-implementation.md)。
