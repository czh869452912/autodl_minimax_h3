# D008 · Agent 移动内容层级与审阅身份

日期：2026-11-07。状态：已实现。来源为 Android mobile 设计指南、unslop 的内容层级原则、本轮现状截图及批准的 N0–N5 计划。

技能目录只承担发现与默认管理，中文用途优先；详情使用现有目录内部全屏 Modal，以确切本地版本 ID 或内置路径寻址。目录保持挂载，搜索、分类与滚动不因查看详情丢失；兼容 initialVersionId，不新增重复路由。会话内完整管理也全屏呈现，底下会话保留挂载，未保存保护复用原合同。短单次选择继续使用可展开抽屉。

历史明确命名为技能运行记录，查询覆盖仅为保存了技能证据的运行，不能代表所有对话或生成任务。详情先读事实状态和消息，阶段按需展开，原始诊断在末尾；不会用当前配置补造历史快照。

R1 复核补充：历史列表按查询身份匹配，切换范围时旧记录不能暂留在新标题下；失败与空态分开。历史是目录内部层，系统返回和页内返回都先恢复目录及其滚动位置，再按实际来源退出；Android 外层 Modal 负责转交原生返回，最终退出仍复用未保存守卫。

生成审阅先读项目、服务账号、未知费用、实际发送内容与人可读素材版本；完整技术证据保留可展开。单次、计划和批次仍共用原 prepare/confirm 与两项独立许可。UI 许可绑定到草稿、修订、项目、账号、准备后请求和固定版本的内容身份；身份变化时重新确认，同一身份重渲染保留已勾选状态。最终提交的领域校验和去重继续生效。

候选与采用读取持久化镜头选择/项目固定关系，不使用归档素材的默认版本推断采用。未知结果导向原任务查询；停止助手与取消生成任务分别表达。没有新增执行状态机、数据库迁移或授权模型。

验证与限制见 [实施记录](../agent-mobile-implementation-2026-11-07.md)。离线 UI、SQLite 行为测试、匹配原生壳采样和真实供应商链验收分别标注。
