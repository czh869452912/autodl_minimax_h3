# D003：将技能添加组织为独立步骤

日期：2026-11-04。状态：M2 源码已接入；设备覆盖以 M2 证据报告为准。承接 D002 的管理与单次选用边界。

旧添加表单位于技能目录上方，来源、用途、格式、示例和安装预览同时增长；正文改变后也可能保留旧预览。采用同一路由中的独立添加任务，每次只显示来源、编辑、检查或安装结果。

复用 `validateSkillPackage`、`readSkillZip`、`createSkillStore.install` 与 M1 单次选择事务。编辑后重新检查，安装审阅的内容，附加文件不因编辑根 SKILL.md 而丢失。安装和启用继续分离；不新增第二份版本或执行状态。

未采用新建多条添加路由，避免把短期草稿塞入路由或增加返回栈；未将目录折叠在表单下方，避免继续混合任务。跨进程草稿持久化不在本切片引入，退出前保留既有放弃确认。

新增 `returnThreadId` 只携带原会话身份；默认管理仍按 projectId 分范围。后续明确选择下次消息时再次核对原会话范围。管理返回若没有提交新的单次选择，仍保留快速层原未确认草稿；明确提交后显示新选择。

实现、测试与边界详见 [M2 报告](../agent-m2-implementation.md)。M1 原有截图保留其版本身份，不当作 M2 设备验收。
