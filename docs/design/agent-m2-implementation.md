# M2：技能添加分阶段

日期：2026-11-04。承接 [实施计划](agent-improvement-plan.md) 的 M2、评估 18–21 和 F4。源码基于 `db7aa4d6` 加本轮已认可的 M1 未提交改动；沿用 Android APK、现有主题、不可变技能版本与安装校验服务。

## 任务与范围

目录添加 → 选择来源 → 编辑 → 检查并安装 → 安装完成 → 查看已安装版本，或明确选用于原会话下次消息后返回。

`SkillAddFlow` 是既有 `/agent-skills` 路由内的独立任务状态。进入添加后不展示目录、筛选、历史或其他版本开关，不增加路由；会话内兼容入口继续推入该路由。

来源有本地文件、手写或粘贴、既有对话提炼入口。手写的“创建草稿”只在本机拼装文本，不调用模型；提炼仍使用既有审阅流程，完整重组留 M5。

| 阶段 | 当前任务 | 返回和异常 |
| --- | --- | --- |
| 来源 | 选择 SKILL.md/单技能 ZIP、手写或提炼 | 导入取消不写入、不丢已有草稿；有草稿时可继续编辑 |
| 编辑 | 用途/约束创建本地草稿，或编辑 SKILL.md | 上一步保留输入；示例、重建正文或新导入覆盖现有草稿前先确认；离开任务复用未保存保护 |
| 检查 | 校验当前正文与包内引用；可查看每个完整文本文件 | 错误回原位；返回编辑后移除旧预览，必须重新检查；ZIP 附加文件保持 |
| 安装 | 主动安装审阅的固定版本 | 再次调用相同校验，失败保留审阅内容、可重试；操作锁阻止重复写入 |
| 完成 | 显示安装结果、查看确切版本、可选单次使用 | 安装不自动改变默认；目录固定将刚安装的版本置顶并展开 |

## 从会话返回

快速层进入管理时，`projectId` 表示管理范围；`returnThreadId` 仅表示原会话，用于安装完成后的明确选用，不让管理目录出现旧单次编辑区。技能正文、输入文字和附件不放进路由。

添加任务打开时读取原会话项目、scope revision、execution epoch；“用于下次消息”复用 M1 的事务校验，范围变化则拒绝写入，已安装版本仍保留。该动作明确替换既有单次选择，不改变项目或全局默认。

快速层正常返回时重读目录：管理没有改已确认单次选择，保留原未确认草稿；安装任务明确确认了新单次选择，则采用新已确认选择，避免把旧未确认勾选显示成安装结果。

## 验证与边界

相关 10 套测试、141 项通过，含真实 SQLite 安装、默认不变、单次选择、范围漂移、附加文件保留、重试、步骤返回、未保存保护及旧预览失效。设备截图、构建身份与具体完成任务见 [本轮证据](evidence/2026-11-04-m2-skills/README.md)。

键盘避让只在编辑阶段的输入框实际获得焦点时启用，避免从原会话或显示设置变化带入旧键盘高度。最终包复核 1.0 字体键盘展开检查、安装定位，以及 2.0 字体来源/编辑/检查；详见截图 30–38。

未安装草稿在当前添加任务内存中保留，明确退出放弃或进程结束后不承诺恢复；已安装版本按原存储持久化。TalkBack、旋转、全部字体档位和大包性能不能据自动测试推断通过。M3 建议/授权/候选、M4 计划、M5 提炼与历史仍待实施。
