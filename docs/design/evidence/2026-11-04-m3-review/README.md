## 前后观察与选择

[前后对照](comparison.png) 将同视口、同一批待审阅对象卡以及同一项目简报审阅成对排列，图片仅缩放并加标签，没有重绘界面。

- 02→05：匿名建议改为项目/镜头具名，变更字段与状态可直接辨认；待审阅对象置前。待处理很多时草稿需下滚；不是声称全部对象在首屏同时可见。
- 03→06：去掉未变化的名称对照，突出唯一变更的简报；明确采用只改文字与状态，不提交生成。
- [处理与回流样本](flow-samples.png)：实际终态和时间保持原主题、卡片与操作层级；采用/拒绝后不残留决策按钮。冲突保留当前内容并移除采用，空草稿进入编辑。
- [大字体样本](font2.png)：2.0 字体下既有项目 tabs 换成两行，新增对照和拒绝可滚动到达；未观察到重叠。页面顶部滚出屏幕是正常滚动，不代表内容截断。
- [最终包回访](final-smoke.png)：摘要仍为 1 项待审阅、1 份草稿；终态对象仍可见，冲突与完善草稿入口保持可用。

视觉复核依据上述成对输入与状态样本：沿用现有绿色主操作、描边次操作、字号、卡片、间距与安全区；未发现新增文本互相覆盖或无法滚动的主要操作。不以此推断全产品无障碍或所有屏宽通过。

## 数据结果与边界

[数据库回读](state-reviewed.json) 只导出合成测试项目所需字段：项目与灯塔修改已采用；港口建议已拒绝且镜头保留原文；海岸建议仍待审阅且手改内容保留。该项目生成任务、授权、外发许可、额度预留均为零。

没有发送助手消息或调用模型、生成服务；回环模型配置没有运行服务器。截图中的文字是明确标注的离线合成内容，不能据此推断真实模型质量。已有无关测试数据未清空，`.beta` 未修改。

业务终态在初始候选完成并被最终包重新读取。进程重启后回访覆盖已存数据读取，不包含任务中途强杀恢复、供应商故障、TalkBack、旋转、全部字体档位、真实长文本或大列表性能。2.0 字体没有验证全部项目页；视频草稿、计划步骤仅有源码/自动回归依据。M3b 请求审阅与配置恢复、M3c 任务/候选仍需各自新鲜基线与完整路径验证。
