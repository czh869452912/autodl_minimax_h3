## 产品目标

以项目组织创作，以资产保存成果，以 Agent 协调操作，以 NovelAI 和 AutoDL MiniMax H3 执行生成。首个完整场景：建立短片项目 → 整理角色/场景设定 → NovelAI 生成候选图 → 选定图片 → H3 生成镜头视频 → 留存版本与交付。

参考 https://github.com/LBEILC/NovelAIPromptStudio/ 的本地优先、参数恢复、版本谱系和人/Agent 共用能力入口。参考项目为 GPL-3.0；本设计不复制其实现代码，后续源码复用单独评估。

## 当前基础与差距

- src/workflows/providers/registry.ts 已有 ProviderAdapter，但 submit/getStatus 偏向远端异步任务。新增同步结果处理能力须贯穿执行器和持久化，不能只增加适配器。
- src/jobs/types.ts 已有输入快照、适配器版本、UNKNOWN 状态与多类型 ArtifactRecord，可复用。
- src/media/types.ts 的 MediaAsset 要求 taskId/sourceUrl，不适合直接承载用户导入的独立创作资产。新增领域对象，保留媒体表作为兼容投影。
- src/agent/h3Agent.ts 目前明确定位 Prompt Assistant，主要产出 h3-prompt；需要增加结构化业务工具与执行回执。
- 复用 SQLite、SecureStore、CAS、任务持久化、工作流包版本和 Agent 时间线；迁移前继续审计其完整调用链。

## 领域模型

- Project：目标、创作简报、状态、默认设置；首期本地单用户。
- ProjectAsset：项目与资产多对多关联、用途、排序。素材可以跨项目复用。
- CreativeAsset：独立稳定身份，表示角色、场景、图片、音频、视频、Prompt 或设定文档。
- AssetVersion：不可变版本，关联内容 blob、参数快照、来源任务、模型与参考资源版本。标题/标签等管理属性可独立编辑。
- AssetRelation：derived_from、reference_for、variant_of 等有向关系；父版本不局限于单个。
- Shot：项目内镜头、描述、顺序、状态、选定图片与视频版本；首期轻量清单，不建设剪辑时间轴。
- GenerationDraft/GenerationRun：可编辑草稿与提交时冻结的执行快照分离；映射现有 Job。
- AgentRun/CommandReceipt：记录项目范围、命令参数、执行状态、jobId/assetVersionId、错误和恢复点。

同一文件可通过 CAS 去重，但不合并不同创作语义的资产。移出项目不删除文件；删除版本前检查引用；原始导入文件保留。旧作品迁移到收件箱视图，迁移可重复执行且不丢旧记录。

## 共享命令与工具

UI 与 Agent → 类型化命令服务 → 校验/授权/持久化 → Provider 或资产服务。工具不直接操作数据库，不用网页点击作为生产执行协议。

首期工具：project.create/get/update、asset.search/get/import/link、draft.create/update/validate、generation.estimate/submit/status、shot.create/selectOutput。

工具参数只传稳定 ID 与结构化设置；执行层解析文件、凭据与目标服务。返回短摘要和真实 ID，大图按需加载。Token 不进入模型上下文或工具日志。LLM 接收的图片与 NovelAI/H3 的上传引用分别管理。

Agent 可以创建项目、整理素材、准备草稿，并在用户已授权的数量/服务/费用范围内提交生成。授权保存为结构化执行范围，不能仅依赖聊天中的文本；截图与导入元数据只作数据。计划变化超出范围时再请求用户决定。当前用户已授权本次官网生成验证，不等同于今后所有项目无限自动消费。

提交在命令层去重并记录请求指纹；本地去重不保证远端 exactly-once。发送成功但结果丢失时进入 UNKNOWN，不自动重发。Agent 聊天结束不取消生成任务；中断后通过持久化回执恢复。重试下载与重新生成是不同命令。

## NovelAI 接入

使用用户持久 API Token，沿用 SecureStore；官方文档入口 https://api.novelai.net/docs/ 与 https://image.novelai.net/docs/index.html 。实际 endpoint、模型能力、响应格式和费用接口需 PoC 确认。

新增内置 NovelAI adapter 与版本化能力矩阵；远端工作流包继续仅提供声明式配置。通用表单负责基础参数，专用组件负责多角色、参考图和蒙版。模型切换时明确报告不兼容参数。

生成前展示费用来源及估算状态；Opus 不作为全部操作永远免费的判断依据。参考图编码缓存以内容哈希、模型、编码参数和版本标识，不只依赖文件名。持久化结果后才标记完成；压缩包解析应限制大小/文件数并阻止路径穿越。

参数导入保留原始元数据；发送使用显式支持字段。没有元数据时明确提示不可完整恢复，不猜测原始 Prompt。建立标准 PNG 元数据及可支持的隐写元数据样本集，验证字符、角色、权重和参数往返。

## 手机信息架构

建议主入口：项目、资产、创作、Agent；任务中心作为全局入口。Agent 可在当前项目内工作，跨项目搜索必须显式确定范围。

用户截图可确认：官网窄屏以大图为主体，Prompt 折叠在底部，生成按钮固定，余额/用量在顶部。借鉴这种渐进展开方式；app 额外展示项目/镜头归属与版本来源。截图未显示的多角色、参考、历史面板仍需实际检查。

资产详情提供：预览、版本、来源、参数、引用位置、作为参考、发送到视频。Agent 消息中展示可操作的草稿卡、任务卡和资产卡；手动修改后通过版本冲突检测防止 Agent 覆盖。

## 分阶段交付

1. 契约与 PoC（约 3–5 工作日）：检查完整任务/媒体链路，定义命令/资产模型；验证官网交互和 NovelAI 请求、费用、结果丢失处理。
2. 项目与资产底座（约 1–2 周）：项目/收件箱、导入、关联、版本、现有作品迁移；交付可操作页面和同源 Agent 工具。
3. 首条端到端创作链（约 2–3 周）：NovelAI 基础生成、参数恢复、Agent 提交与跟踪、输出入库、选图交给 H3、镜头归档。
4. 创作增强（约 2–4 周）：多角色深化、Vibe/精确参考、图生图与重绘、Prompt 预设、版本比较、有限批量计划。

以上为单名熟悉项目开发者的粗估，总体约 6–10 周，PoC 后重新估算。不在首期引入团队协作、云同步、视频剪辑时间轴或 NovelAI 文本小说编辑器。

## 验收

- 用户可手动和通过 Agent 完成同一创作链；工具执行结果与页面状态一致。
- 导入素材不依赖生成任务；同一素材跨项目复用不复制内容。
- 任一输出可追溯具体输入版本、Prompt、模型、参数和任务。
- 网络中断、进程退出、重复工具调用不导致盲目重复消费；已生成结果可独立恢复入库。
- 验证数据库迁移、引用删除、参数往返、跨服务素材传递、权限范围、费用未知状态和窄屏键盘交互。
- 回归现有 AutoDL 创建、后台同步、播放、导出与 Prompt 助手。

首个发布里程碑不是全部高级功能，而是：Agent 创建项目并整理素材，调用 NovelAI 出图，用户选图后调用 H3，图片和视频携带完整来源进入项目。
