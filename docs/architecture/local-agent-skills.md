# 本地文本技能与运行快照

实现日期：2026-10-29；数据库 schema 29。入口：项目协作 → 本地技能。

## 使用闭环

粘贴 SKILL.md 或选择 Markdown/单技能 ZIP → 检查并预览 → 安装不可变版本 → 显式启用 → 下一次默认助手或项目会话运行读取。安装不代表启用；同名技能可保留多个版本，但默认绑定只选择一个。首版不提供脚本执行、模型自动发布、角色库或技能商店。

文本必须含 YAML `name`（小写英文短名）和 `description`；ZIP 根目录或唯一外层目录下包含一个 SKILL.md。支持 `.md`、`.txt`、`.json`，最多 32 个文件，压缩输入及解压文本均不超过 512 KiB。检查路径穿越、大小、CRC、重复文件名、符号链接、加密条目、本地 Markdown 链接；声明额外依赖/工具权限的包拒绝安装。外部链接保留为文本，不自动下载。自由文本提及的程序不执行，未实现对所有自然语言依赖的语义检测。

ZIP 解压使用固定 fflate 0.8.2 的增量 Inflate，逐小块限制实际输出；不将包路径写到设备文件系统。API 参考：[fflate 官方项目](https://github.com/101arrowz/fflate)。

## 持久实体与所有权

| 实体 | 所有者与内容 | 删除/备份规则 |
| --- | --- | --- |
| agent_skill_versions | 应用技能库；正文文件 JSON、内容 SHA-256、元数据、撤销代数 | 正文有不可变触发器；首版只撤销不物理删除，保留历史引用 |
| agent_skill_bindings | 默认助手；技能名到固定版本，最多 8 个 | 显式启用替换同名绑定；不会改变进行中的运行 |
| agent_skill_runs | threadId/runId；版本 ID、撤销代数、执行 epoch | 同一运行只捕获一次；删除会话清除其快照，版本不随会话删除 |

正文自包含于 SQLite，原 ZIP/Markdown 不再是运行依赖，没有新增外部文件或 CAS 引用。既有完整本地备份同时保存数据库与媒体文件，因此包含技能库、绑定和历史引用；首版没有独立项目包导出，不能宣称项目分享已支持技能携带。恢复后执行 epoch 改变，旧运行快照不允许直接执行；新运行重新捕获，恢复本身不会启动模型。旧会话无技能快照时保持可读，下次运行才捕获当前绑定。

迁移前沿用数据库备份；从 schema 28 增量创建技能表和约束。降级 APK 无法写入 schema 29；如确需降级，先恢复迁移前完整备份，新版本之后产生的数据不能通过降级保留。

## 运行边界

每次已持久接受的运行开始时，在事务中捕获默认绑定。随后构建当次 DeepAgents graph，固定只读后端中的版本内容。框架发现名称用本地命名空间避免覆盖内置技能，数据库保留用户原文与完整内容哈希。工作区摘要的技能摘要键包含内置与本地文件；换技能后不会复用旧摘要。重试是新运行，会明确使用当时启用的版本，可在技能页面的最近运行快照核对。

启用新版本不取消旧运行；“停用并撤销”递增撤销代数，通知相关活动运行取消，并在每次模型/工具调用前重新校验。不能撤回已经完成或已由服务商接受的任务；任务仍受原有结构化授权与持久调度管理。关闭技能页面不会取消 Agent。取消/完成均释放撤销监听。

技能没有授权能力。工具集合、项目范围及消费预算仍由现有领域工具和授权检查决定；技能正文不能授予权限。内置及本地技能后端都拒绝修改。

## 验证与范围

真实 SQLite 测试覆盖原子安装/绑定、内容不可变、重复捕获、切换/撤销、恢复 epoch；真实 DeepAgents 图读取固定本地技能，验证发现、只读、换版本不漂移、撤销阻断后续调用。AG-UI 测试覆盖每次运行使用新图与取消清理。Android 模拟器验证检查、安装、显式启用、重启保留与撤销。没有以真实付费模型验证技能的创作质量；这不影响版本及权限契约测试，但不能据此声称任意导入技能有效。
