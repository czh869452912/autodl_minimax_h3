# B.1 A/B Gap Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在进入 Durable Executor 前，闭合 WorkflowPackage 信任边界、Registry 激活一致性、Runtime provenance、下载安全和 Android 验证门禁。

**Architecture:** 所有远程/Git workflow 必须保留并验证完整 `WorkflowPackage` envelope；Registry 以事务方式安装并切换 active/previous。Provider 下载使用 adapter capability 传入的 HTTPS/host/size/MIME policy，Android 构建使用受支持 JDK 与匹配 ABI。

**Tech Stack:** React Native 0.86.3, Expo SDK 57, TypeScript 6, Jest 29, expo-sqlite, Gradle 8.13。

**Spec:** `docs/superpowers/handoffs/2026-09-01-c-d-stages-handoff.md`。

## Global Constraints

- 不引入业务后端、云端数据库、webhook 或远程 orchestrator。
- Git 内容只能是签名声明式 JSON 数据；不得下载或执行脚本、插件或动态 adapter。
- RegistryRecord 必须保留 package hash、source、trust、repository/ref/commit provenance。
- Provider artifact 只能访问 HTTPS、公开允许的 host，并受 redirect、MIME、size、timeout 限制。
- `local.properties` 不修改；不使用 debug keystore 作为 release 签名。
