# Agent 手机工作台修正

## 实机反馈与原因

用户提供的截图显示，工作台标题、项目操作、当前项目范围和会话栏叠在一起；浮动输入框、创作信息按钮和底部导航进一步压缩对话。执行过程展开后还会显示思考摘要和工具 JSON，成果卡片位于整个时间线的末尾，无法稳定发现。

工具返回 `status: error` 时，框架层工具调用仍可能正常结束，原界面会标成“完成”。助手对话结束也不能证明媒体生成完成。

## 当前交互

- 项目切换合并至会话栏，保留历史和新建对话入口；项目管理与授权撤销在项目选择页内。
- 输入框默认单行，内容增长到限定高度后内部滚动。附件、发送保留，引用附件、创作信息、Prompt 版本和全屏编辑进入更多菜单。
- 输入框按正常布局占位，时间线独立滚动，移除浮动覆盖与对应的高度补偿。
- 运行过程默认折叠，结束后自动收起；工具参数、原始输出和思考摘要按需展开。工具业务错误显示为“未成功”，运行摘要提示有操作未成功。
- 输入框上方固定一个 44dp 的“本会话创作”入口，显示草稿、排队、生成、失败、待核查或实际可查看成果数量；读取失败显示重试状态。
- 点开后查看草稿、任务详情、授权和已归档成果；生成图片可直接打开原图预览。完整日志不再阻挡成果入口。
- 底部模式导航最低高度由 66dp 缩至 48dp，保留安全区和键盘时隐藏行为。

## 状态依据与边界

创作活动读取当前会话的命令回执、草稿、`workflow_jobs` 和 `creative_output_links`，以文件资源的可用状态决定是否显示可查看成果。只显示当前项目范围的对象，读取前后核验项目范围及 revision，切换会话清除旧预览。

“仅有草稿”“请求已提交”“生成完成但等待归档”“原件待恢复”和“已有成果可查看”分别呈现。助手文本和工具函数的正常返回不作为媒体完成依据。本轮没有修改提交、授权、计费或重试规则，没有发起付费生成请求。

活动面板展示最近的创作对象，不替代项目素材库或完整任务中心。手机上的既有会话及原始日志保留，无数据库迁移。
