# 工作台、任务、设置与结果管理

2026-10-25 · beta.8

## 统一结构

- 工作台右上角固定任务与设置入口。任务入口用数字表示进行中任务、异常色表示待处理任务；点击打开锚定右上角的最近任务气泡，可直达详情或完整队列。已归档任务不占角标。
- 画布不再插入“正在提交 / 查看本次任务”状态行。生成按钮仍展示当前生成状态，任务详情承担完整状态与异常处理。
- 创作记录保留缩略图摘要，底部导航改为横向换行工具区。
- 队列默认展示缩略图、两行描述、时间和状态，下载、取消、归档、移除等操作需展开；异常任务仍可进入详情处理。
- 任务详情把结果预览放在前面，任务说明位于下方。结果、历史版本与手动相册保存共享现有组件。
- 设置页自行管理唯一标题和返回键，分类内返回分类、分类首页返回来源工作台。系统返回键遵循同一层级，未保存草稿机制保留。

## 图片保存

新增独立的“图片生成后自动保存”偏好，默认关闭，位于设置 / 存储与导出。视频原有偏好保持原义。图片导出在结果归档事务内创建持久化 EXPORT 操作，使用原有导出执行器与恢复机制；自动和手动导出共用 generation 1，避免重复入相册。保留应用内原件。

已保存状态显示在结果与任务缩略图。手动保存的提示作为浮层，不改变画布高度；自动保存完成不弹出占位内容条。

## 全屏

翻页动画到达目标后保持原轨道位置，由已加载的目标图覆盖交接；主图完成加载后移除覆盖层。不同版本使用独立图片 key，Android 默认图片淡入关闭，避免动画归零或图片解码间隙露出旧图/空白。保留缩放、对比、边界回弹与减少动态效果支持。

## 验证

- 全量回归运行：250 套件、1,622 项通过；新增任务弹层用例发现测量回调前不打开的问题，修复后该用例单独通过。其余 1 套件 / 4 项为既有跳过项。
- 后续受影响的导航、设置、队列、预览及导出回归：10 套件、88 项通过，1 项跳过；最终预览与结果入口再次进行针对性检查。TypeScript 检查通过。
- Android 模拟器 720×1280、density 320：验证右上角气泡、单层设置返回、真实图片任务提交、任务角标、紧凑队列缩略图、首屏结果预览、双向全屏翻页。
- 使用已有订阅授权提交 1 次 NovelAI 生成；提交前后画布位置不变。通过 Android MediaStore 查询确认 PNG 位于 Pictures/AutoDL-H3，验证自动保存真实落盘。
- 自动保存开启/关闭、归档重放、随后手动导出不重复创建操作均由真实 SQLite 测试覆盖。
- 手机 ARM64 / ARMv7 包独立构建；最终小改动（取消 Android 图片淡入、相册入口与提示细化）通过针对性测试，未在物理手机检查闪帧。

## 2026-10-25 · 视频提交、参考素材与任务摘要

- 视频工作台仅在本次提交/保存期间锁定操作，不再等待上一任务结束。仍通过 immutable submitted draft 的复制创建下一次请求，保留上一任务输入、关联和结果。
- 图片/音频各自直接进入系统选择器；图片按剩余配额多选，音频启用 multiple。先检查整批数量和格式，再导入，最后一次 replaceVideoMedia 关联全部版本。移除和排序在编辑器内完成，去掉参考素材分类抽屉。
- 最近任务、折叠任务卡片、任务详情均提供排队/执行时长。活动时长更新，完成时使用保存的服务端执行时长。
- 任务卡片保留摘要，只在其下展开操作；180ms 布局动画遵循减少动态效果设置。图片任务合并重复结果入口，移除双重分隔与不必要留白，列表关闭 Android clipping 避免高度变化时裁切。
- 任务结果及素材详情中原先直接置于 ScrollView 的 flex 视频播放器缺少有限高度，改为有明确高度的容器。视频列表使用已有视频封面或视频图标，不再轮询图片输出。
- 单版本素材不再展示无用的版本选择栏；视频未知状态仍可核查，但不再提示解除等待后才能继续生成。

验证：类型检查与相关组件/提交持久化/计时测试通过。模拟器 720×1280、320dpi 上实际验证最近任务计时、任务展开收起、系统图片多选两张并一次关联（2/9）、当前页移除恢复为0/9、音频入口直接打开文件选择器。通过系统文件选择器导入仓库 unified-tracks-test.mp4，在素材详情原生播放器显示画面并播放至00:08结束，无 crash buffer 记录。测试素材名称 qa-video-flow.mp4；测试图片关联已移除。

限制：当前模拟器没有 AutoDL 账号，未向服务端发起真实并发视频生成；提交隔离及重复点击保护通过自动化测试验证。音频批量关联通过组件测试验证，设备上验证了正确的系统选择器入口。
