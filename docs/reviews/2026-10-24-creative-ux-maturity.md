# 创作交互成熟化迭代

日期：2026-10-24

## 本轮判断

这版已从“功能入口集合”收敛为可连续使用的创作流程。针对上一轮记录的交互问题完成三轮迭代：状态驱动的下一步、编辑与冲突保护、设置/错误反馈和移动端可见性。现有离线可验证的主要路径可进入日常试用；真实服务端生成全链路仍需要已配置测试账号验收，不能据此宣称生产验收完成。

停止本轮迭代的标准：用户能够找到下一步；继续操作不会无意创建新草稿；未保存输入不会在返回、关闭或切页中静默丢失；状态改变不会静默覆盖当前输入；失败原因和恢复入口可见；主操作在常规及 1.5 倍字体下可达。

## 用户路径

1. **独立创作**：创作首页选择图片/视频 → 写描述 → 工作台调整 → 连接对应账号 → 明确确认生成 → 同页查看进度与成果 → 保存/继续修改/制作视频。
2. **项目制作**：项目概览 → 镜头清单 → 无参考图则选图/出图 → 已有草稿则继续原稿 → 已提交则看进度与候选 → 采用图片后制作视频 → 审阅已采用视频。另建草稿置于更多操作。
3. **镜头编辑**：打开独立编辑面板 → 填名称、动作与运镜，选择状态 → 保存后返回原列表；关闭或系统返回遇未保存修改时明确确认。
4. **素材复用**：全库按类型/名称查询 → 查看版本 → 加入项目或制作视频。支持加载更多，不再先截断最近 100 项再过滤类型。
5. **助手协作**：进入助手 → 缺少模型配置则直接定位模型设置 → 选项目 → 助手草稿可手动接管 → 看当前项目剩余授权 → 无可用授权时显式授权一次 → 查看结果卡片。
6. **异步冲突**：无本地修改则同步最新草稿；有本地修改则保留输入、暂停保存/提交并提示冲突 → 用户明确选择载入最新版本。提交前仍检查 revision，存储层乐观锁继续生效。

## 实际改动

### 状态与输入保护

- 首页图片/视频描述分别保存在设备安全存储，切换类型、系统字号变化或重新打开应用可恢复；进入工作台成功后仅清空已转交的描述，避免重复建立同内容草稿。
- 镜头主操作按已有草稿/已提交任务/已采用成果决策，不再每次点击创建新草稿。
- 已归档项目仍可审阅已采用视频；概览明确说明归档状态与恢复方式。
- 镜头表单独立为 Modal，关闭、系统返回、项目路由离开均保护未保存内容。保存期间禁止输入。
- 图片与视频草稿在聚焦期间检查最新 revision；有本地修改时显示冲突并暂停写入，用户确认后才载入最新内容。
- 素材信息增加取消修改入口；不存在的项目显示恢复导航，不再出现无上下文操作区。

### 信息层级与反馈

- 设置顺序：创作账号 → 助手模型 → 存储 → 旧工作流；顶部提供快捷定位。
- 助手缺少配置时直达“创作助手模型”，不再先看到旧 AutoDL Token。
- 明确新创作账号与旧工作流 Token 的使用范围；账号面板回到前台时刷新状态。
- 镜头编辑有固定字段标签、突出保存按钮、已选状态标识；失败提示在编辑面板内显示。
- 常见领域错误和参数校验转换为中文提示；视频错误只在确实有未保存输入时附加保存提醒。
- 草稿出现错误/冲突时滚到提示位置；任务中心空态改为“开始创作”。
- 单任务页准确标注“同步任务状态”，说明其同步任务中心且不会重新生成。

### 素材与授权

- 素材类型筛选下推数据库，列表与选择器均支持按 100 项增加加载量，最多显示 1000 项后引导搜索缩小范围。
- 助手显示当前项目、当前有效账号的未知费用可用授权次数；已被预留、已撤销、旧账号、旧执行周期和过期授权不计入。
- 已有可用授权时不再引导重复授权，确认授权时重新检查项目范围与当前余额。
- 隐藏已丢弃草稿的助手成果卡片。
- 草稿同步、助手范围/卡片、成果与素材导出状态轮询绑定页面焦点，离开时清理。
- 系统字体变化时复位键盘引起的底栏隐藏状态。

## 仍须真实账号验收的边界

模拟器未配置 NovelAI、AutoDL 创作凭据或 LLM。真实生成、Agent 工具执行、下载、相册导出权限、UNKNOWN 查询恢复和多候选采用，只能以现有自动化覆盖为依据，尚未完成本轮真实服务端端到端验收。这是发布验收的独立条件，不应把本轮交互收敛等同于生产链路全部通过。
