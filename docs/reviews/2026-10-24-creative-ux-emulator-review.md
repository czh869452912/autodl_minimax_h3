# 创作 UX 模拟器验收与页面逻辑复查

日期：2026-10-24

## 结论

已在 Android 模拟器上实际操作创作、项目、镜头、素材、助手入口、设置入口和任务页面，并安装修复 APK 复测。发现并修复了 H3 视频草稿无法解析本地工作流的阻断问题，以及导航、素材状态、反馈和重复操作方面的问题。

此次不能认定付费生成全链路通过：模拟器没有配置 NovelAI、AutoDL 创作凭据和 LLM。未提交付费生成、未发起真实 Agent 会话；真实图片/视频生成、下载后预览、相册权限和 Agent 成果回流仍需接入测试环境验收。

## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| H3 草稿始终报工作流未安装 | 新草稿使用本地 catalog ID；准备与提交兼容旧草稿中的服务端 ID。真实 SQLite 回归覆盖新旧草稿，模拟器旧草稿现已正常到达账号检查。 |
| 项目归档后跳成列表但路由仍是项目详情 | 保持当前项目详情，刷新归档状态并直接显示恢复入口；更多操作中可找到归档。模拟器完成归档→恢复。 |
| 素材详情从其他页面返回后不刷新 | 改为页面重新获得焦点时读取素材、版本、使用位置及回收站状态；未保存素材信息时保留当前编辑，避免刷新覆盖输入。 |
| 版本链接失效导致预览区域空白 | 指定版本不存在时回退至有效默认版本或最新版本；同素材的 versionId 参数变化同步到选择状态。组件回归覆盖。 |
| 不存在的素材链接显示成普通素材库 | 显示不存在提示及返回引导，不再混入导入入口。组件及模拟器验证。 |
| 回收站状态只依赖路由参数 | 改为读取实际存储状态；恢复前隐藏继续创作和设置默认版本。模拟器完成导入→移入回收站→恢复。 |
| 类型筛选无结果时空白 | 按筛选后的列表判断空态，提示调整搜索或类型。模拟器验证有图片、切换视频类型的场景。 |
| 视频导入参考图可能重复打开选择器并与保存冲突 | 从打开系统选择器到导入/写入结束全程加锁；取消后释放编辑。组件测试验证双击和取消，模拟器验证系统选择器取消。 |
| 失败/取消/未知任务仍提示等待成果 | 无成果时提示查看任务原因；成功状态不再一直显示“正在整理”。代码走查修复，未以真实付费任务验收。 |
| 助手切换项目后反馈不可见 | 成功关闭选择弹窗后，反馈显示在当前项目区域；异常仍可在弹窗中看到。代码走查修复。 |
| 项目简报、素材信息未保存就返回会丢失 | 增加原生返回/路由离开的确认；项目页签切换、取消简报编辑也提示继续编辑或明确放弃。新增组件回归；项目简报在模拟器复测。 |

## 模拟器操作覆盖

设备：emulator-5554，Medium_Phone_API_37.0，1080×2400，字体比例 1.0。包名：com.example.autodlh3。

| 路径 | 实际观察 |
| --- | --- |
| 创作→图片工作台→空提示词生成 | 正确提示填写图片或角色提示词，没有产生任务。 |
| 项目→镜头→添加镜头→选参考图 | 镜头创建成功；无素材时显示解释；取消返回原镜头列表。 |

| 创作→视频工作台→输入描述→返回→继续编辑 | 自动保存成功，重新打开仍保留 UX-camera-pan。 |
| 视频→导入参考图→系统相册→取消 | 返回原草稿，无参考图增加，可继续操作。 |
| 旧视频草稿→生成视频 | 修复前报“H3 工作流尚未安装”；修复后提示绑定 AutoDL 创作凭据，连接按钮可展开凭据表单。 |
| 项目→更多→归档→恢复 | 保持项目详情；恢复后助手入口重新出现。 |
| 素材→导入测试截图→详情 | 缩略图、版本、预览可见。导入图片无 NovelAI 元数据时明确说明无法恢复提示词。 |
| 素材→筛选视频 | 显示无匹配素材，不再空白。 |
| 素材详情→回收站→恢复 | 回收站详情保留预览与恢复入口，隐藏视频创作入口；恢复后从回收站列表消失。 |
| 不存在的素材/任务深链接 | 显示不存在提示；任务页仍有任务中心入口。 |
| 助手→未配置提示→打开 LLM 设置 | 能进入设置页面；未填写或修改密钥。 |
| 任务中心 | 空队列、筛选和创建引导正常显示；本轮未产生生成任务。 |

## 尚待处理的页面逻辑

下表为未纳入本轮修复的事项；“代码确认”不等于已完成真实服务端端到端测试。

| 优先级 | 问题与依据 | 建议及验收标准 |
| --- | --- | --- |
| P1 | 图片/视频草稿只按 id 首次加载。Agent 或其他入口更新同一草稿后，原页面可能仍持有旧 revision。代码确认：ImageDraftScreen / VideoDraftScreen 的加载 effect。 | 返回时检查 revision；本地无修改则刷新，有修改则明确解决冲突。验收：Agent 修改后返回，不静默覆盖、不反复自动保存失败。 |
| P1 | 镜头名称/描述编辑尚无统一离开保护，项目内部切页会卸载表单。代码确认：ProjectShots。 | 将镜头表单脏状态纳入项目切页及返回保护，或独立持久化编辑草稿。验收：系统返回、切页、切换镜头都不静默丢字。 |
| P1 | 镜头“制作视频”只看采用的图片/视频；未检测已有编辑草稿或进行中的任务，每次点击可新建草稿。代码确认：ProjectShots。 | 优先展示“继续草稿/查看生成进度/审核候选”，主动再生成才建立新草稿。 |
| P2 | 新创作凭据与旧设置中的 AutoDL Token 分开，助手设置仍描述为仅优化视频提示词。模拟器及代码确认。 | 设置按“创作账号/助手模型/旧工作流兼容”分组，入口定位目标区域，并明确凭据适用范围。 |
| P2 | 本次任务的“查询原任务进度”实际调用全局 maintenance 刷新。代码确认：creative-task/[id]。 | 增加按 jobId 查询能力，或准确标注全局刷新；每次操作有明确完成/失败反馈。 |
| P2 | 任务空态仍叫“去生成视频”，实际入口落到默认图片创作首页。模拟器及路由语义复查。 | 改为“开始创作”，或明确传递视频模式。 |
| P2 | 部分非法数值/领域错误直接显示校验信息；视频错误统一附带“修改尚未保存”提醒，即使草稿已保存。代码及模拟器确认。 | 时长、种子等字段就地显示中文错误；保存错误、连接错误、任务错误采用不同恢复动作。 |
| P2 | 素材只加载最近 100 项后在前端过滤类型；类型空态不能代表全库。代码确认：service.assets / CreativeWorkspace。 | 类型筛选下推查询并增加分页；空态区分“最近记录无匹配”和“全库无匹配”。 |
| P2 | 助手授权卡片未汇总当前有效额度，重复授权的累计效果不直观；多处轮询离开页面后仍存在。代码确认：AgentCreativeCards / AgentCreativePanel。 | 显示有效授权余额与撤销入口；仅在聚焦/执行期间刷新，避免后台持续查询。 |
