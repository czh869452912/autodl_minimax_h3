# 对话与素材详情的界面收敛（2026-10-30）

## 研究依据

- [Eagle：Organize](https://en.eagle.cool/support/desktop/organize)：以标签、文件夹、智能文件夹组织素材，并分别提供浏览、筛选和 Inspector。借鉴内容浏览与信息检查分区；不照搬桌面三栏到手机。
- [Eagle 官方：标签工作流](https://www.eagle.cool/blog/post/streamline-file-management-how-eagle-tags-boost-design-assets-organization)：介绍标签、列表/网格及信息面板配置。采用标签可见、描述可读的详情信息块。
- [Google Photos：查看图片信息](https://support.google.com/photos/answer/15532903?co=GENIE.Platform%3DAndroid&hl=en)：先选图片，再由更多 → About 查看信息。借鉴预览优先、低频操作面板化。
- [Android Developers：Icon buttons](https://developer.android.com/develop/ui/compose/components/icon-button)：图标应有清晰含义，适合常用操作；提供常规、填充与描边样式。采用返回、编辑、导入、更多等熟悉图标；“加入项目”等业务动作保留文字并明确按钮边界。
- [Immich：外部素材库](https://docs.immich.app/features/libraries/)：外部素材与其他素材共用浏览和相册组织。保留全局素材与项目关联模型，不因改 UI 复制原件。

以上是公开文档研究与本项目的设计推导，不声称完成这些产品的实机对比测试。

## 落地

1. 创作页移除左上角重复“创作”标题，保留图片/视频切换和工具图标。
2. 助手直接恢复项目对话，不再先显示项目列表，也没有“返回项目选择”。项目切换只在对话左上角；无进行中项目且无指定会话项目时，提供“前往项目”。创建项目统一在项目页。
3. 对话历史仍由历史图标打开，搜索覆盖全部对话；新建会话继承当前会话的实际项目。任务和更多菜单合并进对话工具栏；技能、助手设置置于更多菜单。
4. 项目素材页使用紧凑页头、明确选中态页签、搜索、类型筛选和网格。导入、制作图片、项目设置为工具图标。移除重复管理说明和技能入口。
5. 素材详情以预览为主体，图片支持全屏缩放。首屏显示格式、本地状态、真实文件大小/图片尺寸、来源、创建日期、描述、标签及项目归属；无法读取的值不伪造。
6. 导出、加入项目、版本是明确描边按钮；编辑名称标签、项目关联、版本历史、其他操作分面板处理。保留默认版本、版本比较、恢复原件、生成参数、增强、封面、移出项目与回收站功能。
7. 仅改变当前涉及页面的动作呈现，不把全应用文字链接机械替换为大按钮。重要动作保留具体名称，无意义承诺和重复说明从浏览区移除。
