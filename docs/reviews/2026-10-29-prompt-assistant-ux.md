# 手工提示词助手改进

- 图片、视频共享讨论组件：固定标题，历史与新建独立按钮，新建直接开启隔离上下文。
- 历史从已有记录提取需求标题、最近答复摘要、轮数，支持主题和答复搜索；保留手动命名和删除。
- 助手占满可用编辑区域，隐藏背景生成底栏；建议默认可选择阅读，支持完整展开及按需编辑，采用操作不再把完整 JSON 作为聊天气泡展示。
- NovelAI 的 propose_prompt/validate_prompt 新增 addCharacters，支持空草稿创建角色、修改已有角色并追加新角色。保留已有角色坐标；新角色使用默认中心位置；模型角色上限与 Medium 负面限制继续校验。新增角色必须显式采用，采用后收起该建议，防止重复追加。
- 系统提示区分共享场景描述和人物描述，鼓励多人构图拆分角色；视频指导包含主体动作、运镜、时间及适用的声音描述。工具仍不自动生成媒体。

- 最终顶部按钮对齐通过 UI 树验证；图片键盘截图：`build/conversation-qa/prompt-assistant-image-keyboard.png`。测试期间 crash buffer 无记录。
