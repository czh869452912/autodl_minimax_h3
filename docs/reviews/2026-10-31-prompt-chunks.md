# Beta 38 — 提示词片段与 Rescale 修复

日期：2026-10-31

## 发现与实现

此前“片段”仅能在当前草稿里维护文字并追加到主提示词，缺少独立持久化片段库和请求阶段的引用展开。

按 NovelAI 官方 Prompt Chunks 文档核对核心语义：https://docs.novelai.net/en/image/promptchunks/ 。内置浏览器控制初始化失败（系统找不到指定路径），本轮未声称完成登录官网界面交互对照。

- 新增本机持久化片段库：名称、内容、新建、编辑、搜索、移除，跨草稿/重启复用；保存失败保留表单。
- 正向、负面、角色正负提示词均可插入 `!macro:名称!`；提示词输入支持 `@` 按名称检索插入，支持展开为普通文本。
- 实际生成请求构建阶段递归展开引用，而非只改变预览。任务快照保留定义，避免未来编辑库影响已提交任务。
- 拦截缺失、重复名称、循环引用、超过16层嵌套、展开超过10000字符；片段库与草稿各最多50个。
- 保存时检查整库依赖有效；仍被引用的库条目不能直接移除；移出库保留既有草稿快照。
- Rescale 标签置于整行上方，数字框与滑条垂直居中，滑轨两端预留手柄空间。步数和引导强度复用同一布局。

范围说明：这是本机片段库；未接入 NovelAI 云端片段同步、分类、拖拽和富文本 chip。使用可编辑引用文本，不冒充与官网全部交互一致。
