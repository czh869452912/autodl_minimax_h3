# Prompt 助手第二、三批实施结果

基线：第一批提交 `050b1edd`。分支：`codex/prompt-assistant-correctness`。

## 第二批：恢复与可观察性

- 将运行与每次重试记录到会话状态：保存原用户消息、输出消息、起止时间、错误、工具步骤和 retryOf。网络失败、停止、完成、意外中断有独立终态，切换会话不会丢失解释和重试入口。
- 重试追加新尝试，保留此前的半成品；模型使用被重试轮次的原输入上下文。冷启动将残留 running 标记为 interrupted，提供“重新生成这一轮”。
- 保存采用 300ms 防抖和 2 秒最大等待；用户消息、工具结果、运行终态、进入后台时 flush。失败保留最新 dirty 快照，间隔重试；修复失败前已排队的 debounce 绕过重试间隔的问题。
- Timeline 按轮次展示真实状态、当前活动、步骤与耗时，失败/中断自动展开。工具失败来自真实 ToolMessage.status，不再由正文关键词推断。只对当前输出启用流动画。
- 已就绪图片及文本草稿随会话恢复；生成时允许准备下一轮草稿。历史图片和提及支持打开预览。历史列表展示运行/未读状态，仅在助手页可见且应用在前台时标记已读。

## 第三批：创作产物闭环

- 已完成并通过格式校验的 Prompt 生成独立版本快照，保存来源消息和图片身份；支持最新版本标记、切换、差异比较、复制和追加恢复版本。
- Timeline 的纯 Prompt 输出只显示一份产物卡片，默认折叠长内容，并标记最新/历史版本；说明文字与未完成内容继续保留。
- 重试旧轮次产生的版本按 run→user 关联原素材，避免把后来上传的同名“图片1”误绑定到旧轮次结果。
- “预览并带入创建页”明确展示文本、图片绑定与参数。图片按稳定编号排序，缺失引用、重复标签和非连续编号会阻止交接，避免创建页按数组顺序绑定时发生错图。
- 预览校验四种内置画幅、1–15 秒整数时长与合法 Seed；留空在创建页采用工作流默认值。创建页再次按当前活动工作流 schema 校验，拒绝不兼容参数。
- 交接草稿保存完整来源、参数与图片数据，兼容旧文本草稿。创建页先读取、验证并将素材保存到应用私有文件，再应用表单，渲染成功后消费草稿；不会自动提交视频任务。
- 导入失败、表单已编辑、工作流/草稿切换或页面卸载时保留未应用的草稿。只接收嵌入图片或本地文件，不隐式下载远程图片；最多 9 张、总计 50MB。
- 添加结构化创作信息入口，填写主体与动作、镜头、风格及期望时长后加入可编辑草稿。

## 边界

本批恢复的是会话、运行记录和可重新生成的输入，不是 LangGraph 图 checkpoint；重新生成可能再次调用工具。结构化信息入口由用户填写，尚未实现模型主动发出的异步问答协议。没有调用真实外部 LLM 或提交收费视频生成。

长期项目化、跨会话素材库、聊天图片 CAS 去重、历史分页和图执行断点恢复属于后续架构工作。当前内嵌图片的聊天快照仍存在大图/长会话的存储与内存成本；交接端已实施单次总量限制。
