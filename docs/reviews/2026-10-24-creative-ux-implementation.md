# 创作 UX/UI 调整实施记录

日期：2026-10-24。依据：`2026-10-24-creative-ux-redesign.md`。

## 已落地

- 导航调整为创作、项目、素材、助手。创作首页提供图片/视频入口和最近草稿；旧工作流视频编辑器及带 prompt/draftId 的旧跳转继续保留。
- 图片工作台常显比例、模型摘要和生成动作；负面描述、角色、高级参数按需展开。账号管理默认收起，连接状态在编辑开始处可见。
- 图片与视频生成会先保存最新输入再准备确认；保存失败不继续提交，连续点击受锁保护。保留自动保存和离开未保存页面的保护。
- 图片/视频结果原位预览，历史图片以缩略图切换；直接继续修改、制作视频、用于镜头或请求导出。查看素材时携带当前版本。
- 视频编辑支持从素材选择、导入及移除参考图片；保留精确版本引用和提交时冻结输入。
- 新增项目、素材、任务独立详情路由。项目概览展示简报摘要、镜头进展、最近草稿和需要处理的计划；没有待处理计划时隐藏对应区块。
- 镜头卡突出下一步，管理操作折叠；选图使用带预览的选择器。图片草稿新增可选 shotId，校验项目归属，支持结果直接采用到原镜头。
- 素材列表增加缩略图与类型筛选；详情只展开一个版本，描述与管理操作收起，加入项目时再展开搜索选择。
- 助手项目范围常显，项目选择使用独立弹层；对话滚动区加入持久化事实驱动的草稿、结果和待审阅卡片。手动接管编辑同一份草稿。
- 生成授权入口随草稿出现，明确当前授权是项目级、一次请求、费用未知且无金额上限。项目切换后校验范围，保留撤销入口。
- 独立任务详情展示当前任务状态、错误、原始草稿入口。未知结果查询不重新提交。
