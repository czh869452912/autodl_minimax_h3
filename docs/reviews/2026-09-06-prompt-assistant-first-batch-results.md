## 已完成

- 流适配显式区分真实 LangChain chunk 与完整消息，保留重复 token 和换行；AG-UI 与旧事件接口共用 reducer。
- 按 message/index/id 聚合分块工具参数，参数完成后再结束参数流；旧接口的工具结束来自真实结果。
- 回传 assistant 工具调用时转换为 LangChain 格式，保留调用/结果对应关系；中断遗留的无结果残缺参数不会阻断新追问。已有结果但参数损坏的历史会明确报错，避免静默丢上下文。

- 持久化附件身份、显示名与结构化提及位置；模型输入在每张图片前附对应标签。删除前图不会使剩余图在历史中重新编号。

- 成功运行持久化最终无工具文本消息的完成凭据；失败、取消、截断、空最终消息均不认证。导出同时检查完成凭据与运行结束，提供进行中/错误反馈和重复点击保护。
