# 手机工作台密度调整与 Beta 33 复审处理

本轮依据用户真机反馈与 `2026-10-31-ux-reaudit-beta33.md`。设计目标是让图片结果重新成为主要视觉区域，把编辑、设置、历史作为按需打开的工作面；不是全局缩小字体。

## 已实现

- 图片工作台采用独立紧凑控件密度：常规工具行 36dp，图标与底部动作 40dp；列表导航仍保留原尺寸。紧凑按钮不外扩 hitSlop，避免邻接命中区重叠。未宣称这些尺寸通过 TalkBack 或全套无障碍验收。
- 删除“可生成 / 提交前确认本次费用与授权”常驻状态行及重复连接按钮；连接入口保留在用量栏。生成按钮视觉、禁用状态与无障碍提示由实际就绪条件驱动。
- 图片画布不再常驻历史缩略条；右下角历史按钮打开原历史面板。关闭历史恢复完整工作区，不改变具体版本和采用语义。
- 收起的编辑抽屉从 76dp 改为 60dp；缩减工具栏、抽屉把手及底部留白。设置展开使用可用高度，模型/画风并排，张数单行，常用参数紧凑排列。
- Steps 与 Prompt Guidance 的输入数字、滑块和无障碍当前值共用拖动预览值；松手提交一次，纵向滚动取消预览，不持续写入草稿。

## 验证证据

- Jest 全量：292 套件、1831 项通过；原有 1 套件 / 4 项跳过。滑条测试检查**拖动中、松手前**的数字与可访问值，保留纵向取消测试。新增封面用途、按需历史、105 项引用分页验证。
- TypeScript 检查通过。最终构建、安装与包信息见同目录证据清单。
- 模拟器设置为 1140×2616px、520dpi、字体 1.0，约 350.77×804.92dp；与用户窗口 350.8×804.9dp 接近，系统上下安全区并不完全相同。
- 同一空草稿、无账号、相同屏幕条件：旧版画布无遮挡范围 y=492–1605px，约342.46dp；新版 y=427–1940px，约465.54dp，增加123.08dp（约36%）。这是空画布布局对比，不代表真实生成结果或所有安全区条件均增加相同比例。
- 设置首屏可见模型、画风、Effort、尺寸、张数、Steps、Guidance、Seed、采样器与高级设置入口。设备拖动后 Steps=38、Guidance=4.2，数值保存；随后通过数字输入恢复为原值23和7。没有提交收费生成。
- 右下角按钮成功打开历史；截图为零结果历史。多结果隐藏常驻条由组件测试覆盖，未用空态声称真实多候选验收通过。
- 浏览器控制初始化两次失败（kernel assets 路径错误），本轮无法读取用户已登录 NovelAI 页，因此未声称已完成官网实时对照。

证据：`docs/evidence/2026-10-31-density-refinement/`。`density-before` / `settings-density-before` 为旧构建同尺寸对比；`image-after` / `settings-restored` / `history-open` 为新布局及交互；`steps-dragged` / `guidance-dragged` 为手势释放后的数值。拖动过程连续联动以回归测试为证。
