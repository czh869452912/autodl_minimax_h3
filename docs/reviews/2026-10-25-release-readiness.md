# 当前版本发布差距评估

评估基线：`92757cb8`，`codex/creative-app`，`1.5.0-preview.4` / versionCode 42。检查本地源码、发布配置及已有验收证据；本次没有安装应用、消费生成额度或触发发布，没有查询远端 CI 和签名 secrets 状态。

## 判断

当前属于功能较完整、近期仍在收敛稳定性的内测版。具备准备封闭 Beta 的基础，尚不足以直接判定正式版可发布。主要差距是最终 Android 产物、升级数据和异常环境下的完整验收证据；近期连续复核仍发现交联问题，不能用测试数量代替稳定性观察。

评估以 Android 手工图片/视频工作台为首发核心：NovelAI V5 Full、Enhance、独立 2× 超分、元数据查看、AutoDL 工作流选择、任务观察、素材管理和备份恢复。Agent 的项目对话与已有有限工具作为实验功能；外部 skills 和完整自主创作不作为这次正式版的承诺。若首发要求双模式都达到成熟生产水平，本估算不适用。iOS、应用商店上架也不包含在此评估中。

## 已有基础

- 统一账号、固定凭据代次、共享执行器、不可变提交快照、发送边界和未知消费隔离已实现。
- 最近完整回归：240 套件 / 1577 项通过；原有 1 套件 / 4 项跳过。TypeScript、5 种恢复场景 / 10 个进程、2 个 workflow release 与 36 文件 skill bundle 验证通过。
- 最近 Android 构建是 x86_64 Debug；更早有原生单元测试、图片仪器测试及窄屏模拟器交互记录，不能当作最终提交的 arm64 Release 验收。
- V5 Full High / Medium、多图、多角色、图生图、重绘与最大画质增强已有真实协议请求证据；Enhance 有 Android 原生发送到归档证据；独立超分有真实接口及原生契约证据。AutoDL 有真实图片到视频接口记录。不能再把这些全部列为“未实现”，也不能据此推断最新完整 App 已经真机验收通过。
- 已有带正式签名校验、版本校验、ABI 和 native alignment 检查的 GitHub Release 工作流。当前分支相对本地 main 有 65 个提交，尚需在候选提交上做集成与正式产物验证。

这些是待关闭的发布条件，不代表六项都已证实存在业务缺陷。特别是签名配置未知不能表述为“没有签名”，缺少最新设备验收也不能表述为“功能不能运行”。

## 不要求在本次发布前完成

- 不强制删除旧 handoff 编辑器、任务投影及媒体桥接。只要明确权威源、对账和恢复行为通过验收，保留受约束的兼容层可以发布；PRIMARY 切换作为独立迁移交付。
- 不以云图库同步、Director Tools、流式预览、镜头拖拽或完整自主 Agent 作为手工工作台首发阻断项。界面与发布说明必须与实际范围一致。
- 不继续扩大所有工作区的 UX 改造。只修复影响主链路、数据、恢复和必要可访问性的缺陷；大素材量分页、长列表性能作为应测量的后续改进，若代表性数据已造成卡死或不可操作则升级为阻断。

## 工作量估计与顺序

粗估以设备、账号和签名资源可用为前提，不是完成日期承诺。主链设备验收和发布产物/升级验证优先，发现缺陷会改变工期。

1. 半天左右冻结首发范围、候选提交和验收矩阵，更新过时文档。
2. 约 2–3 个有效开发/验收日完成核心 arm64 链路、正式产物和基础升级检查，修正直接阻断，可准备封闭 Beta；连同准备和反馈留约 3–5 个工作日。
3. 进一步完成异常矩阵、代表性旧数据/备份恢复和缺陷回归，总体暂留约 5–10 个有效开发/验收日，并安排 48–72 小时稳定性观察。稳定正式版按约 1–2 周规划，发现付费重复提交、数据丢失或升级失败则重新估算。

当前下一步应当是发布冻结和验收，而非继续新增功能或一次性清空全部旧架构。
