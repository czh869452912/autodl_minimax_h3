# UX 改版后的前后端交联复核

本轮沿工作台输入、账号状态、原子提交、后台执行、异常恢复、结果归档与旧入口逐段检查。发现并修复了四组问题；没有发现需要恢复两套生成后端的理由。

## 已修复

| 问题 | 原因与影响 | 处理 |
| --- | --- | --- |
| 绑定账号后返回视频工作台，按钮可能仍不可用 | `videoAccountReady()` 只在草稿加载时执行；返回页面时草稿未变化，`useDraftSync` 不会再次加载 | 账号就绪检查独立于草稿，在每次页面获得焦点时重新读取；初始未完成检查时禁用生成，保留现有输入 |
| 图片 UNKNOWN 任务不能走完“核查后继续创作” | 图片把 UNKNOWN 一直计为等待；任务详情的解除等待操作只对 AutoDL 显示 | 图片与视频使用同一等待 hook；两类任务详情都能记录人工核查。只解除下一次手工生成的等待，原任务、授权和费用记录不变 |
| NovelAI 异常被引导到 AutoDL | 任务队列和任务详情中的核查文案及网址写死了 AutoDL | 使用统一的展示信息选择对应服务商；NovelAI 提示核查本次结果与消费记录，不虚构远端任务历史 API；未知适配器使用通用提示，不套用 AutoDL 网址 |
| 统一账号后仍保留旧 Token 表单契约 | 兼容视频表单通过 `readSettings()` 将 Token 读入页面并回传，而提交服务又解析了一次账号；通用设置类型、保存、校验和草稿仍携带旧字段 | 表单只读取布尔就绪状态；提交服务自己解析一次当前凭据并冻结 ID。通用设置移除生成 Token，旧设置草稿忽略该字段；`autodl.token` 仅保留在账号模块的历史迁移入口 |

页面的就绪状态用于提示和控制交互，不能替代提交前校验。兼容提交入口在当前账号和源素材预检成功后才写入任务，避免留下无法执行的占位任务。任务持久数据只存账号、凭据代次和服务商 ID，不存 Token。

## 逐段确认的边界

| 链路 | 复核结果与证据 |
| --- | --- |
| 视频工作流选择 → 编辑 → 后端参数 | `workflowVideoState` 保留工作流版本/哈希及完整 values；现有 `videoPipeline.test.ts` 验证额外数值 0、布尔 false、素材及真正 HTTP 序列化，不能仅按页面快捷字段构建请求 |
| 兼容表单 → 提交命令 | 新增真实 SQLite 测试：就绪检查后切换账号，最终任务绑定提交时的账号；提交解析一次凭据；缺少账号或原件时 jobs/operations 均为零 |
| 创作提交 → 执行 → 查询 | 沿用统一 `providerExecution`；创作任务使用预算绑定，兼容新任务使用 SUBMIT 固定引用，只有无绑定的历史任务保留默认账号路径；现有真实 SQLite 回归覆盖账号切换、失效绑定和发送前失败 |
| UNKNOWN → 人工核查 → 新尝试 | 两个路由组件用例验证对应核查入口、确认后调用及返回现有画布。真实 SQLite 用例分别覆盖 NovelAI、AutoDL：核查幂等、不新增 SUBMIT、不改 UNKNOWN、不释放 UNKNOWN_HELD；沿用旧授权再次提交被拒绝，新授权才可创建新任务 |
| 输入自动保存 → 不可变提交 → 结果观察 | 图片和视频继续使用独立结果草稿观察已提交内容；编辑下一次输入不会改写原任务。图片新增回归确认核查后主动生成会复制提交草稿，保留原结果 |
| 结果 → 下载 → 素材 → 相册 | 保留独立操作、读取投影和 CAS 原件引用；完整测试覆盖现有媒体命令、归档、相册状态、恢复和账号断开后的 NovelAI 持久收据 |
| 通用设置 → 创作账号 | 通用设置不再读取或写入 `autodl.token`；账号连接、固定代次、撤销与旧密钥迁移只由账号模块负责 |

## 仍保留的旧结构及原因

- **兼容视频编辑器与旧 create 路由**：仍承接历史 `agent_handoffs` 的应用、确认与素材引用转移。当前手工视频工作台是主要入口，但尚未把旧交接协议完整迁移过去。直接删除会让已保存交接草稿失去入口；它共用现有提交命令和执行器，不拥有另一套账号或生成后端。
- **`tasks` 读取投影**：提供任务列表、下载及导出状态，`workflow_jobs` 保存执行事实，两者用途不同。保留投影修复与读取一致性测试，不能通过删表把两类状态混为一谈。
- **旧媒体映射与迁移捕获**：旧下载链路仍通过 `media_assets` 写入，素材管理以 creative assets/CAS 读取；`creative_legacy_assets` 等记录负责桥接、引用和历史删除边界。去掉桥接前需要先完成所有写入方迁移。
- **历史无绑定任务的默认账号兼容**：只适用于确实没有固定绑定的老记录。损坏绑定或创作预留缺失必须拒绝，不能自动降级。
- **生成授权与账号绑定**：前者限制请求范围、次数、预算和代次，后者用于解析秘密与查询原任务。两者不能合并成“已连接即可无限重试”。

后续最值得继续收敛的是旧提示词交接协议：将旧 handoff 原子迁入创作草稿并迁移素材引用后，才能整体删除兼容表单。此次不通过重定向丢弃历史参数，也不增加新的双轨编辑入口。
