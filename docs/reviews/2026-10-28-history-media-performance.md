# 结果历史、缩略图与视频记录读取

## 实现

- `f2722088`：结果历史使用 `(created_at,id)` 游标，每页默认 40 条。搜索在数据库执行，覆盖页外提示词、Seed、版本号。列表/比较入口虚拟化；完整预览、Enhance 原图、前后相邻结果独立查询，跨页不依赖已加载数组。数据库 v28 增加资产历史及全局版本分页索引。
- `4ffbe84c`、`86580de9`：图片先按尺寸降采样，生成最长边 640px 的 PNG 缩略图，保留透明度与 EXIF 方向。视频软件解码封面复用磁盘缓存。创作预览缓存限定 64 MiB / 512 文件；JS 共用两路解码、48 个待处理请求、128 个 URI 缓存。移出屏幕的未开始请求取消，队列拥挤时可见项稍后重试；缓存丢失时尝试重建。旧任务已持久记录的 poster URI 仍位于持久目录，不受创作预览缓存清理影响。
- `6f0ede06`：视频历史直接按 provider/project/shot/session 查询，移除通用草稿列表 100 条上限对本页的截断。任务、输出链接按 200 个 ID 分批查询；列表只传轻量成果字段，不传完整 recipe。旧 schema 的 recipe-linked 成果有批量兼容路径。轮次序号仅变化时保存，稳定序号查找改为 Map；页面失焦停止读取。
- 后续验收补充：并发加载/过期搜索/新结果插入测试，计数使用“已载入”和 `+`，不冒充总历史数量。

## 验证

- 全量 Jest：270 套 / 1700 项通过，原有 1 套 / 4 项跳过。之后新增分页竞态 2 项通过；最终结果页与分页 hook 共 19 项回归通过。TypeScript 通过。
- SQLite 1000 版本测试：同时间戳稳定排序、全量翻页无漏项/重复、新版本插入、首屏以外搜索、相邻页访问、查询索引；迁移及 schema parity 回归通过。
- 450 轮现代视频测试：7 次查询（1 次 scoped draft + 3 批 jobs/outputs），不会混入另一会话；成果 recipe 故意损坏也不影响轻量列表。另有旧 recipe-linked 成果兼容测试。
- 原生 `PreviewDiskCacheTest` 2 项通过：大尺寸降采样上界、仅清理已完成的专属预览、不删原件或进行中 part。Android x86_64 beta 构建通过，覆盖安装已有 schema27 数据成功。
- 模拟器检查：素材选择器两版本实际缩略图、图片生成历史、旧版本切换、全屏按钮显示所选原图。截图 `build/conversation-qa/history-media-thumbnails.png`、`history-media-result-history.png`；日志 `build/history-media-android.log`、`history-media-full-tests.log`。未发起付费生成。

## 边界

- 未给出内存降低百分比：只有单次 meminfo 快照，没有同设备前后受控基准。大图采样与队列上界是实现保证，不能替代低内存真机压力测试。
- 历史在用户持续翻页时保留已读行以支持比较/多选；首屏和刷新不再全读，但不是只保留一页的滑动内存窗口。
- 关键词搜索可扫描匹配资产的 recipe；本轮没有新增全文索引或 prompt 投影表。视频记录批量读取也不等于无限历史的独立 UI 分页。
- 当前画布、全屏及相邻页仍使用原图；本轮主要消除历史网格重复解码原图，没有重写放大浏览器的解码架构。
- 模拟器现有样本量较小；1000 版本、450 轮规模由数据库/组件测试覆盖。未声称在设备上跑过同规模性能压测。
- 未发布新的手机 APK；本次 Android 产物用于模拟器验收，原 beta.19 手机下载文件保持原版本。
