本轮承接 `2026-10-28-performance-audit.md` 与 `2026-10-28-mobile-ai-creative-ux-research.md`，交付范围是可安装测试的增量版本，不将研究中的全部长期事项宣称完成。

## 已提交的实现

## 交互与事实边界

- 预览选择不等于镜头采用；只有明确点击“用于此镜头”才执行带 revision 的采用命令。
- 返回上下文只携带项目/镜头 ID 和页签。项目/镜头数据仍从持久服务读取，不复制到新的全局状态。
- 路由中的镜头不存在时显示说明并展示可用镜头，不自动建立或替换镜头。
- 现有视频工作台会从持久草稿恢复对应生成轮次；不再新增另一套播放/候选页面。
- 选材、采用、导出等使用边界仍保留完整性检查；只移除浏览所有历史时的重复检查。

## 自动化验证

- TypeScript 无错误。
- 全量 Jest：267 套通过，1693 项通过，原有 1 套 / 4 项跳过。
- 原生 `NovelAiTransportTest`：9 项通过，覆盖慢生成不阻塞回执/媒体工作、并发发送门闩和损坏回执。
- 跨进程恢复：5 种场景、10 个独立进程通过，包括 UNKNOWN、已知远端句柄、部分文件等。
- 固定工作流发布包及内置技能包校验通过。
- 新增回归覆盖分页边界、翻页期间新增版本、文件状态变化、未变化历史不重读、采用视频与镜头返回、已采用后继续查看候选。

测试日志保存在本地 `build/usable-*.log`、`build/beta19-full-tests.log`、`build/native-isolation-tests.log`。APK 和 Android 验收结果另记于 `docs/testing-phone-beta.md`。

## 明确保留的后续事项

2026-10-30 更新：以下为 beta.19 当时的遗留清单，其中“逻辑素材去重”已在 beta.25 实现，详见 [去重与补全验收](2026-10-30-import-dedup-and-tag-completion.md)；不能继续作为未完成项统计。孤儿文件清理和内存优化仍待独立实施。

- 结果详情首次进入仍读取当前资产的版本集合；轻量状态检查仍随版本数量增长。独立缩略图、详情/比较页全面虚拟化、结果页全游标分页尚未完成。
- 视频记录的逐轮任务查询、部分终态保存状态轮询、Agent 卡片其他关联读取仍可继续批量化。
- 原生线程池已隔离，但队列容量、请求优先级和取消策略还没有全面重做。默认派发预算修复不等于所有恢复调用都有硬超时。
- 大图/base64 峰值、备份排除临时文件、孤儿 CAS/回执清理及逻辑素材去重需要单独的安全生命周期设计，本轮不自动删除或合并用户素材。
- 受控测试与模拟器验收不代表真实账号端到端生成或低内存手机性能验证；这些应在手机测试中继续确认。
