# 项目、资源与技能入口整理

用户反馈 beta.25 基本功能正常，但项目与资源管理界面简陋，部分能力难以找到；进一步指出技能管理和 3D 导演台。

## 已有能力与实际交付边界

- 技能管理已实现：导入、检查、安装、启用/撤销，以及从对话证据提炼、保存草稿、审阅发布。此前入口只有项目协作/助手中的“本地技能”，可发现性不足。
- 3D 导演台只有隔离的静态场景实验，未接入生产资产/草稿，也未完成目标手机资源预算验证。当前不提供空白或不可用入口，不把设计当成已交付能力。
- beta.24 已完成技能提炼；beta.25 已完成独立导入素材的逻辑去重。早期计划中的对应待办已被这些后续实施记录取代。

## 本批调整

- 项目列表与素材库顶部提供管理说明卡和“技能管理”入口；说明技能可以导入、提炼和启用。项目列表提供“打开素材库”。
- 项目详情提供明确的项目管理区域、当前归档状态、编辑简报和归档/封面管理入口。
- 素材库回收站直接可见；素材详情的名称/说明/标签编辑和加入项目不再需要先打开“更多”。
- 音频独立筛选；搜索提示准确说明可搜索名称、说明和标签。
- 项目列表、概览、镜头和素材详情不再无条件读取素材列表；素材页不再读取无关项目封面。

## 后续独立批次

1. 历史记录游标分页、缩略图与列表虚拟化，保留精确版本定位和比较语义。
2. 大文件内存峰值、临时文件备份策略与孤儿文件清理：先明确引用和恢复契约，再实施可审阅的清理流程。
3. 3D 产品化：完成目标设备内存预算和生命周期验收，接入场景版本、PNG 成果及来源追溯后，再开放正式入口。

此批只改善已有能力入口，不宣称完整 UI 重设计或整个性能路线图完成。

## 验证

- 相关 2 组 / 13 项测试通过；TypeScript 通过。
- Android x86_64 debug 构建成功。初次打包遇到 Gradle 2 GB 堆内存不足，单次构建调整为 4 GB / 单 worker 后通过，未修改应用内存配置。
- Android 17 模拟器完成素材库到技能库（可见导入和提炼）、回收站往返、音频素材信息/加入项目入口，以及新建项目后打开归档管理。截图和 UI 树 `build/management-*`；未调用模型。测试后原数据库逐字节恢复，无 WAL 遗留。
- 本批未重新生成手机 beta 分发包；用户当前的 beta.25 不包含这些新入口。
