# GUI / UX 优化与验收

## 已实现

- 生成页简化重复标题，固定底部生成按钮和参数摘要。所有禁用条件共用逻辑与外观，白色图标与主按钮配色一致；附件操作沿用统一主题。
- 页面打开时预检本地 AutoDL Token，缺失或读取失败时提供设置入口。保存设置后发布无敏感信息的变更通知，生成页自动更新提示；实际提交仍重新读取配置并执行原有校验。
- Android / iOS 使用键盘避让；表单独立滚动，底部操作区保持可见。校验失败在底部展示汇总提示。
- 任务列表读取结构化 STATUS_SYNC 状态和错误码，区分凭据失效、暂停待核查和自动重试。查询异常不会把生成状态改成失败，也不会自动重新提交 UNKNOWN。
- UNKNOWN 优先提供核查原任务：展示时间、描述、本地编号，支持复制及打开 AutoDL；明确本地编号不是远端任务编号。重新创建保留重复消耗提示与二次确认。
- 归档/恢复/核查按钮提供至少 48dp 点击高度；运行中的移除按钮外观与禁用逻辑一致。任务编号改用末尾八位，卡片描述限两行，简化计时区背景。
- 监控和刷新增加可见文字；任务页页头随列表滚动，给大字体留出空间。空归档页解释归档语义并返回全部任务；无活跃任务时隐藏历史监控停止提示。
- 作品页增加显式管理入口。零选中时仍保留管理模式，避免点选变成播放；删除按钮在未选中时禁用。
- 设置说明改为面向用户的用途解释，明确助手配置可跳过，保存状态注明尚未验证连接。未新增自动连接探测或生成请求。
