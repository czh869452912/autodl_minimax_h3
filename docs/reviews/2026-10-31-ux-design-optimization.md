# UX/UI 优化设计与实施状态

依据：执行交接包、主审计、19/57/21/55 截图和当前源码。采用 Product Design 既有产品上下文原则：保留四入口、主题与版本体系，以任务连续性为目标，不全局换皮。

## 本轮已修改

- F01：镜头主操作只由已采用成果决定；无图片时持续显示选择参考图、制作参考图；有图片后显示制作视频和换图。全部编辑/已提交草稿独立列出，按更新时间排序，显示类型、序号和时间，进入各自原草稿/进度页。
- F02：区分项目空、筛选空、全库空；提供切全部素材、清除搜索、取消返回；加载错误不再同时显示空库结论。保留目标与显式版本确认。

## 全局设计合同（后续实施）

| 范围 | 优化规格 | 验收重点 |
| --- | --- | --- |
| A1 健康状态 | 缺原件显示恢复原件，不回退到未制作 | 缺文件、恢复、并发 revision |
| A2 导入回流 | 选择请求保留目标镜头和 revision；导入/生成后定位新候选再确认 | 取消、拒权、失败、目标删除 |
| A3 就绪 | 补描述、连接具体服务、核查用量、可生成、提交中分开；连接后回原草稿 | 离线、未授权、未知任务、防重复 |
| B1 表面 | 用带 asset/version 的单一 activeSurface 表示菜单/工具；返回依次处理键盘、工具、任务、来源 | 遮罩/系统返回一致、编辑保护 |
| B2 触控 | 48dp 布局目标，保留 hitSlop 直到边界实测；相近图标加短标签，大字体换行 | 窄屏、1.0/1.3/2.0字体、读屏、安全区 |
| C1 最近工作 | 标题、项目/镜头、媒体、状态、时间、缩略图、精确打开目标统一；命令活动自然语言化 | 同名空草稿、删除来源、多候选 |
| C2 封面与导出 | 设置提供选择封面，预览具体版本后确认；统一保存到手机，状态来自 delivery | 取消无写入、拒权、未知核查 |
| D1 技能 | 快速面板仅选用/查看，导入编辑提炼全屏；用途先于格式；保存与启用分开 | 不可变版本、run快照、停用、提炼证据 |
| D2 计划与维护 | 空项目先补镜头/图片；授权列输入版本、规格、次数、时效、估价币种；维护分日常空间/完整备份/数据库/危险区 | 过期授权、防重发、隔离恢复 |
| E 资源性能 | 只读摘要，复用健康与 delivery，按对象事件刷新前先测量 | 100/1000/10000版本、缺Blob、后台恢复 |
