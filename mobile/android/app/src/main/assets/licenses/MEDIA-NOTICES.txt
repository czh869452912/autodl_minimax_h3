Rebuilding/relinking:
1. Extract ffmpeg-kit-source.tar.gz and the FFmpeg/cpu_features archives.
2. Follow the included Android build instructions with NDK r27d. Populate
   src/ffmpeg and src/cpu-features from the matching archives if offline.
   Build the min main variant using ./android.sh --disable-arm-v7a
   --enable-android-media-codec --enable-android-zlib (upstream release recipe).
3. Replace the Maven FFmpegKit dependency in mobile/android/app/build.gradle
   with your built AAR using implementation files('libs/modified-ffmpeg-kit.aar').
   The application's complete JavaScript and native source/build scripts are
   available at the matching AutoDL release tag.
4. Run npm ci --legacy-peer-deps in mobile, then :app:assembleDebug in
   mobile/android using the documented Android SDK/JDK. You can sign a release
   with your own key; our private signing key is not required. Android may
   require uninstalling the original app before installing a differently
   signed APK; export your media/data first.
